# Social Integrations

![Social](/docs/images/integrations/social.svg)

Social provider records are catalog-only in the current SI docs. There is no current `si` root command for these integrations.

Planned social surfaces cover:
- Facebook Graph API
- Instagram Graph API
- X API
- LinkedIn API
- Reddit API

## Current Status

Do not document or automate social workflows as executable SI commands until an owning implementation is restored in SI or moved to the standalone `orbit` repo.
