# si Documentation

SI is an operations-first CLI for secure secrets, Codex/Nucleus runtime controls, wrapper entry points, browser MCP execution, and release build workflows.

## Start here

1. Install SI:
   - npm: `corepack pnpm install -g @aureuma/si`
   - Homebrew: `brew install aureuma/si/si`
2. Build and verify your local binary from source when needed: `si build self`
3. Validate secret setup: `si fort doctor`
4. Inspect command surface: `si --help`
5. Validate docs before publishing changes: `si mintlify validate`

## Best-practice workflow for docs updates

1. Update or add the relevant page.
2. Update `src/lib/data/aureuma-docs.json` navigation at the same time.
3. Run `si mintlify validate`.
4. Run `si mintlify broken-links` before publishing.
